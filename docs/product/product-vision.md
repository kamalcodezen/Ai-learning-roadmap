# Product Vision: AI Pather

> **Document Status**: Reconstructed from the implemented system.  
> **Target System**: AI Pather (Repository: `Ai-learning-roadmap`)  
> **Tagline**: Transforming static tutorial purgatory into an adaptive, proof-backed technical career intelligence engine.

---

## 1. Long-Term Mission

AI Pather exists to bridge the gap between self-directed technical education and enterprise software hiring standards. By treating learning as a dynamic dependency graph rather than a static linear checklist, AI Pather equips developers with real-time feedback, authentic code simulations, architectural guidance, and tamper-proof verification tokens that prove competency to employers.

---

## 2. Core Strategic Pillars

```
+-------------------------------------------------------------------------+
|                               AI PATHER                                 |

+------------------------------------+------------------------------------+
```

### Pillar 1: Dynamic Learning Graphs
- Learning is modeled as a Directed Acyclic Graph (DAG) of competencies rather than a linear syllabus.
- Nodes represent milestones and concepts; edges represent strict prerequisites.
- Blocked nodes are isolated to reveal underlying knowledge gaps, prompting targeted remedial sub-nodes.

### Pillar 2: Resilient Multi-Tier AI Gateway
- Generative AI powers intelligent curriculum customization, contextual mentorship, and code grading.
- Zero downtime design: The system never crashes or returns HTTP 500 when external LLM providers experience token rate limits (HTTP 429), timeouts, or service outages.
- A seamless cascade rotates across multiple accounts and providers with self-healing JSON parsing.

### Pillar 3: Authentic 4-Stage Simulations
- Developers are evaluated through the actual day-to-day responsibilities of software engineers:
  1. *Understanding* core mechanics.
  2. *Debugging* broken production snippets.
  3. *Writing* code that satisfies strict structural patterns.
  4. *Explaining* engineering trade-offs in plain technical language.

### Pillar 4: Proof-Backed Portfolio & Career Verification
- Moving beyond "trust me" resumes: Projects are validated directly against GitHub repositories, inspecting test suites, containerization, and commit history.
- Verifiable proof graphs generate cryptographically signed, shareable tokens for recruiters and hiring platforms.
